Tentang DTP Software Developer

DTP Software Developer (sebelumnya pecahan antara DTP Programmer dan Hipster) merupakan kelas peminatan Digital Talent Program yang berfokus pada pengembangan perangkat lunak berbasis web.

Selama pembelajaran, siswa mempelajari desain halaman web (UI) dan pengalaman pengguna (UX) serta dasar hingga teknologi modern seperti HTML, CSS, JavaScript, React, Laravel, Next.js, database, Git, dan pengembangan project secara kolaboratif.
